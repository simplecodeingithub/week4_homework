## Exercise 12 – Collections  
This exercise focuses on understanding Python collections, including lists, tuples, and dictionaries.  

### Collection Types:  
* **Lists** – Ordered, mutable (can be changed), and allows duplicate values.  
* **Tuples** – Ordered, immutable (cannot be changed after creation).  
* **Dictionaries** – Key-value pairs, used for fast lookups and structured data.  
* **Sets** – Unordered collection of unique values, does not allow duplicates.  

### Tasks:  
1. **List Operations:**  
   * Fix issues with list modifications.  
   * Learn how to append and extend lists properly.  
2. **Tuple Behavior:**  
   * Understand how tuples work.  
   * Learn why a single-element tuple needs a trailing comma.  
3. **Random Numbers:**  
   * Generate 6 unique random lottery numbers using Python's `random` module.

## Exercise 13 – File Handling  
This exercise teaches how to read from and write to files in Python.  

### Tasks:  
1. **Writing to a File:**  
   * Create a file called `pelican.txt`.  
   * Write a limerick to the file using Python's `write` and `writelines` methods.  
2. **Reading a File:**  
   * Read the entire contents of `pelican.txt`.  
   * Display the type of the returned data.  
   * Convert file contents into a list and count the number of lines.  
   * Use a loop to iterate over and print the contents without blank lines.  
   
### Files:  
* `write_file.py` – Writes a limerick(a short poem with 5 lines) to `pelican.txt`.  
* `read_file.py` – Reads and processes the contents of `pelican.txt`.
